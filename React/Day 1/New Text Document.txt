TASK 4 – DOM, VIRTUAL DOM & RECONCILIATION

Read and prepare answers for:

1. What is DOM?
	 Dom stands for Document Object MOdel.
The browser converts an HTML document into a tree-like structure called the DOm.
<body>
  <div>
    <h1>Hello</h1>
    <p>Welcome</p>
  </div>
</body>

JavaScript can interact with this structure to change the webpage.


2. What is Virtual DOM?
The term virtual Dom is commonly used to describe React's in-memory representation of the UI.
react can create an updated representation of the UI and compare it with the previous one to determine what changes are needed.

3. What is the difference between DOM and Virtual DOM?

	DOM				Virtual DOM
Browser's actual document structure	In-memory representation used by React
Represents the actual UI document	Represents what React wants the UI to be
Browser manages it			React manages its UI representation
Updates can affect the actual page	Used to determine necessary UI changes

4. What is Reconciliation in React?
	 Recociliation  is the process React uses to determine how the current UI should be updated when the components output changes.
example.
<h1>Hello</h1>
<h1>Welcome</h1> -- react determines that the text inside the heading needs to change.

5. What is Diffing?
Diffing means comparing the previous UI representationn with the new one to determine what has changed.


6. How does React identify changes in the UI?
	React uses the new output of components and compares it with the previous output.
IT considers things such as:

element type
position in the tree 
Component identity
Key values in lists


7. Why is key important while rendering lists?
key helps React identify individuals items in a list.
helps React identify each list item between renders.
A good key should be stable and unique among the items in that list.

Prepare answers for:

1. What is Rendering?
Rendering is the process where React calls components to determine what UI they should produce.

2. What is Re-rendering?

	A re-render means React runs a component again to determine its updated UI output.

3. What causes a component to re-render?

Parent re-render:
when a parent component renders, its child components may also render.

Context Update:
A component consuming context can re-render when the relevant context value changes.
Props changes can alse result in a component rendering with new input.


4. Does re-render mean the complete browser DOM is recreated?
NO.
this is one of the most important concepts:
Suppose your application contains:

Header
Navbar
Main
Footer

If only a value inside Main changes, React does not simply throw away the entire browser DOM and recreate the whole webpage.

React determines which changes are necessary and commits the required DOM updates.

5. What happens during reconciliation?
When React has new component output, it compares it with the previous output and determines what needs to change.

Previous UI
    ↓
New UI
    ↓
Compare
    ↓
Determine changes
    ↓
Commit necessary DOM changes

this process is called reconciliation.
